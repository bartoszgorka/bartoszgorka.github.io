# Security

This repository holds the source of my personal blog, [bartoszgorka.com](https://bartoszgorka.com).
It is a static Jekyll site built and deployed by GitHub Pages through GitHub Actions.

If you find a security issue (for example a vulnerable dependency that affects the published site,
a compromised link, or a leaked secret), please e-mail **bartosz@bartoszgorka.com** instead of
opening a public issue. I will respond as quickly as I can.
